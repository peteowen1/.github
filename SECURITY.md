# Security policy

This policy applies to every repository under `peteowen1` that doesn't have its own
SECURITY.md.

## Reporting a vulnerability

Report it privately through GitHub. Don't open a public issue.

1. Open the repository's **Security** tab.
2. Click **Report a vulnerability**.

Please include:

- the repository and file, or the URL, where the problem is
- what an attacker could do with it
- the steps to reproduce it

## Scope

In scope: code in these repositories, their GitHub Actions workflows, and any secret
that has leaked into them.

Out of scope: the data files published as release assets. They are public sports and
election data, not secrets.
